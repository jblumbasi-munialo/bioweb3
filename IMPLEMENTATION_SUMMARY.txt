🏗️  ARCHITECTURE

Module Loading Flow:
  1. Load Feature Flags (bio-flags.js)
  2. Load 6 Core Modules (~800 lines)
  3. Register Service Worker
  4. User clicks tab → Lazy-load feature (30-300KB each)
  5. Smart cache/network handling

Caching Strategy:
  ┌─────────────────┬──────────────────┬─────────────┐
  │ Content Type    │ Strategy         │ Cache TTL   │
  ├─────────────────┼──────────────────┼─────────────┤
  │ Core JS/CSS     │ Stale-While-Revalidate │ 30 days │
  │ Features        │ Cache-First      │ 30 days │
  │ API Calls       │ Network-First    │ 5 sec   │
  │ Images          │ Cache-First      │ 60 days │
  └─────────────────┴──────────────────┴─────────────┘
