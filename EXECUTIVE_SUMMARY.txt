TROUBLESHOOTING
█████████████████████████████████████████████████████████████████████████████

Problem: npm install fails
   Solution: 
      rm -rf node_modules
      rm package-lock.json
      npm install

Problem: Build produces errors
   Solution:
      npm run clean
      npm install
      npm run build

Problem: Service Worker not registering
   Solution:
      → Check console: swManager.getStatus()
      → Check DevTools > Application > Service Workers
      → Try: swManager.unregister() then reload

Problem: Old content in cache
   Solution:
      → Run: swManager.clearCache()
      → Then: Reload page

Problem: Feature not appearing
   Solution:
      → Check: featureFlags.showDevTools()
      → Verify: Feature enabled in features.json
      → Current env: featureFlags.getEnvironment()
